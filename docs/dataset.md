# Dataset

Подготовка датасета для обучения детектора дронов.

## Итоговый состав

| Компонент | Изображений | Назначение |
|---|---|---|
| Anti-UAV300 | 33,438 | Дроны в небе (RGB + IR) |
| Roboflow: drone detection | 2,190 | Дроны крупным планом |
| Roboflow: UAV Detection | 12,866 | Разные типы дронов |
| Roboflow: Quadcopter | 10,882 | Мультикоптеры |
| Roboflow: bird vs drone | 1,621 | Различение дронов и птиц |
| Hard negatives: Custom Workflow | 2,778 | Дорожные знаки, разметка |
| Hard negatives: Self Driving | 7,000 | Улицы, машины, пешеходы |
| **ИТОГО** | **~68,000** | |

**Финальный сплит:**
- Train: 61,376 (17.8% негативов)
- Val: 9,399 (12.7% негативов)
